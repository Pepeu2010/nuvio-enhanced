# Créditos do código

Telumia é um projeto independente que evolui os clientes open source de NuvioMedia. A marca e o logo do Telumia são próprios. Licenças, autoria e histórico upstream são preservados nos clientes, conforme as licenças originais.

- Base Desktop: [NuvioDesktop](https://github.com/NuvioMedia/NuvioDesktop), commit de referência em `docs/upstream-lock.json`.
- Base Android TV: [NuvioTV](https://github.com/NuvioMedia/NuvioTV), commit de referência no mesmo registro.
- Os contratos de serviços herdados são mantidos enquanto a implementação evolui. Um novo nome não transforma esses serviços em infraestrutura independente.

Os registros de auditoria e evidências anteriores usam os nomes que vigoravam quando foram produzidos; não são reescritos para aparentar validação de uma versão posterior.
